🎯 Key Features Implemented

🔄 Automatic EMI Collection

Automatically blocks a percentage of each transaction as EMI payment based on loan terms.

📅 Scheduled Payments

Auto-pays collected EMI amounts to lenders on specified dates each month.

📊 Real-time Dashboard

Live tracking of EMI collections, outstanding amounts, and payment schedules.

🏢 Multi-Lender Support

Manage multiple loans from different lenders with consolidated EMI tracking.

💰 Transaction Management

Easy transaction entry with automatic EMI calculation and collection.

🔐 Secure API

RESTful backend with Spring Security, data validation, and error handling.

🔧 Technical Stack

Backend: Java Spring Boot, Spring Data JPA, H2 Database, Spring Security

Frontend: React + TypeScript, Material-UI, Recharts, Axios

Features: Scheduled EMI processing, Real-time calculations, Role-based access
